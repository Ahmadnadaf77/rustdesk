╔══════════════════════════════════════════════════════════════════════════╗
║  🔄 BUILD PROCESS FLOW                                                   ║
╚══════════════════════════════════════════════════════════════════════════╝

Step 1: Build Rust Backend
───────────────────────────
Command: cargo build --release
Output: target/release/rustdesk.dll (Windows) or librustdesk.so (Linux)
Purpose: Creates the core RustDesk library

                    ↓

Step 2: Build Flutter Frontend
───────────────────────────────
Command: cd flutter && flutter build windows --release
Input: Uses the Rust library from Step 1
Output: flutter/build/windows/x64/runner/Release/
        ├── rustdesk.exe
        ├── flutter_windows.dll
        ├── librustdesk.dll
        └── data/

                    ↓

Step 3: Package Complete Build
───────────────────────────────
Action: Copy ENTIRE Release/ folder
Result: Complete, working Windows application!

RustDesk is built with:
  windows_subsystem = "windows"

This means:
  ✓ No console window appears (looks professional)
  ❌ No error messages shown to user
  ❌ Program just doesn't start

To see the actual error on Windows:
  cmd /c rustdesk.exe

Expected error message:
  "The code execution cannot proceed because flutter_windows.dll 
   was not found. Reinstalling the program may fix this problem."
